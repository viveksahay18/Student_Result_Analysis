# Student Result Analysis

This project performs Student Result Analysis using Data Analytics.

## Features
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Visualization
- Grade Calculation
- Attendance Analysis

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Power BI

## Run the Project

### Step 1
Install required libraries:

pip install -r requirements.txt

### Step 2
Run the project:

python analysis.py

## Dataset
Dataset file is located inside:
data/student_data.csv

## Output
- Final Report CSV
- Graphs and Visualizations
